# 🛡️ E-Rakshak

> **An Intelligent Cyber Fraud Detection & Awareness Platform**

E-Rakshak is a cyber safety platform developed to help users identify and avoid common online scams before becoming victims. The application analyzes suspicious SMS messages, WhatsApp chats, QR codes, and call recordings, then provides easy-to-understand risk assessments along with recommended actions. Designed with accessibility in mind, it supports multilingual interaction and a simple user interface suitable for users of all technical backgrounds.

---

## 🚀 Features

- 📩 SMS Scam Detection
- 💬 WhatsApp Message Analysis
- 📞 Call Recording Analysis
- 📷 QR Code Scam Detection
- 📂 Evidence Upload & Management
- 🌐 Multilingual Support (English, Hindi & Gujarati)
- 🔊 Voice-Assisted Guidance
- 📜 Scan History
- 🔐 Google Authentication

---

## 💡 Problem Statement

With the rapid growth of digital payments and online communication, cyber fraud has become increasingly common. Many users struggle to recognize phishing messages, fake payment requests, malicious QR codes, and social engineering attacks.

E-Rakshak aims to simplify cyber safety by providing an easy-to-use platform that helps users identify suspicious digital content and make informed decisions before taking any action.

## 📌 How It Works

1. Login securely using Google Authentication.
2. Choose the type of content to analyze.
3. Upload or enter the suspicious content.
4. The system analyzes the input and generates a risk assessment.
5. View recommendations and maintain a history of previous scans.
